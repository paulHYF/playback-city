## 原型

| 版本 | 文件 | 说明 |
|---|---|---|
| v1 | `prototype/v1-dungeon-2d-pixel.html` | 2D 像素地下城，完整闭环 |
| v2 | `prototype/v2-dungeon-3d-stone.html` | 3D 石砖地宫 |
| v3 | `prototype/v3-night-city-song.html` | 宋风地上广场 + 店铺经济 + 地下地宫 |

## 已实现功能

| 端 | 功能 |
|---|---|
| 运营后台 | 输入频道号导入 · 逐讲生成地宫 / 生成整城 · 游戏配置展示与调整（服务端校验）· 11 套地宫主题 · 原始数据查看 · 观众闯关数据 |
| 观众端 | 城防舆图首页 · 地上回放广场（楼阁 = 回放）· 地宫闯关（10 种殿室机制、门题与道具链、巡夜怪、破惑对决、Boss 五步对决）· 答错封印看回放 · 结算与 D+1/3/7 复习 · 带货铺子与商品讲解片段 · 进度落库可续打 |
| 讲师助教 | 助教大盘（立体点亮城、殿室漏斗、错误率、复活回看热度、错题榜与干扰项）· 点进观众闯关明细 |
| AI 分析 | 直播质量分析报告（培训 / 营销双维度、直播在线曲线与流失点、回放补看与重点回顾段）· AI 复盘点评（写给讲师 / 主播）· 竹简长文版 |

## 演示视频工程

`demo/`：`script.json` 分镜与旁白 · `record.mjs` 分段自动录屏 · `build.py` 配音 / 字幕 / 合成 · `cards.html` 片头片尾卡。任一段可单独重录，见 [README](../README.md) 目录表。
